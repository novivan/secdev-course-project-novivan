# P12 - Сводка по харденингу безопасности

## Безопасность Dockerfile (Hadolint)
- Используется фиксированная версия Python (3.11-slim)
- Создается пользователь без прав root (appuser)
- Многоступенчатая сборка уменьшает поверхность атаки
- Установлены правильные права доступа к файлам

## Инфраструктура как код (Checkov)
- Просканированы Kubernetes манифесты (namespace, deployment, service, network-policy)
- Настроен security context (пользователь без root, read-only файловая система)
- Установлены лимиты и запросы ресурсов
- Сетевые политики для изоляции трафика
- Реализованы liveness и readiness пробы

## Безопасность контейнерного образа (Trivy)
- Образ просканирован на уязвимости
- Результаты доступны в trivy_report.json

## Результаты сканирования безопасности
- Hadolint: 0 ошибок
- Checkov: 0 ошибок
- Trivy: 0 найденных уязвимостей
